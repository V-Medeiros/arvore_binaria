# Árvore Binária de Código Morse

Programa em Java que usa uma árvore binária para converter texto em código Morse e Morse em texto. Contém as letras de A a Z e os números de 0 a 9.

Funcionamento

Cada Node guarda um caractere e dois filhos. Um ponto (.) segue para a esquerda e um traço (-) segue para a direita. O caminho da raiz até o caractere forma seu código Morse.

Opções do menu
1. Converter texto para Morse.
2. Converter Morse para texto.
3. Buscar uma letra ou número.
4. Inserir um caractere.
5. Mostrar a árvore.
6. Mostrar o exemplo SOS.
0. Sair.

execute:

javac Main.java
java Main

Use texto sem acentos ou pontuação. No Morse, separe as letras com um espaço e as palavras com /.
